# 今日宝可梦卡面设置

[返回首页](../README.md) · [配置与管理](ADMIN.md) · [卡片预览](CARDS.md)

在 AstrBot 插件配置，或宝可梦图鉴管理台的「研究站设置」中，找到「今日宝可梦卡面风格」。

管理台会同时展示三套卡面的五档预览，点击「查看大图」可放大。选择样式后点击「保存配置」；「待保存」表示尚未生效，「使用中」表示当前已保存的样式。

| 选项 | 卡面 |
| --- | --- |
| 现有稀有度卡面（`classic`，默认） | 保留森林、冰晶、紫晶舞台、黑金与珍珠全息五种卡面 |
| TCG 收藏卡面（`tcg`） | 参考 Pokémon TCG 的卡牌构图、边框、属性图标与稀有度材质 |
| 游戏王收藏卡面（`yugioh`） | 凹槽姓名框、属性圆章、星标、金属画窗与五档纸面或闪箔工艺 |

[查看 TCG 五种卡面预览](CARDS.md#tcg-收藏卡面) · [查看游戏王五种卡面预览](CARDS.md#游戏王收藏卡面)。

保存后，下一次发送「今日宝可梦」会使用所选卡面，单抽与多抽均支持。没有设置此项时继续使用现有卡面。

「游戏王简介纯黑粗体」（`yugioh_profile_black_bold`）默认关闭，沿用当前字体。开启并保存后，游戏王卡面中宝可梦的简介正文会改为纯黑粗体，单抽与多抽均生效；姓名、进化等其他文字，以及其他卡面保持原样。

三套样式均以「文字提示＋纯卡牌图片」发送。次数、星尘、保底和新增收藏显示在文字里；卡牌保留宝可梦自身资料，并用属性能量图标显示弱点、抗性和免疫。较长的进化或特性资料会补在文字中，图鉴摘要只在卡内显示简短内容。

卡面切换只改变今日宝可梦图片的外观，收藏、图鉴和对战卡保持原样。普通与闪光仍显示对应个体，抽取概率、次数、星尘和保底规则也保持一致。

关闭「启用图片卡片」时返回文本；图片生成失败时会发送本次抽取结果的文本，不会重新抽取。
