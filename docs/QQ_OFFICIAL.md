# QQ 官方 Bot

[返回首页](../README.md) · [玩法与指令](COMMANDS.md)

在 AstrBot 中接入 QQ 官方机器人后，本插件会自动识别官方平台，用原生 Markdown 排版抽卡结果、收藏、图鉴资料和对战战报，并保留所选的完整卡面。开通按钮权限后，可直接点击再抽一次、翻页、兑换和挑战等操作。

## 接入与配置

先在 QQ 开放平台配置机器人，并在 AstrBot 中启用 QQ 官方 Bot 适配器。应用凭据由 AstrBot 管理，插件无需再填写 AppID、Secret 或 token。

QQ群和 C2C 自定义 Markdown 已于 **2026 年 4 月 23 日全量开放**，默认 `auto` 模式可直接使用原生排版，不必申请 Markdown 模板。频道自定义 Markdown 仍受邀请测试权限限制；**消息按钮有独立权限**，Markdown 可用不代表按钮一定可用。

| 插件配置 | 默认值 | 说明 |
| --- | --- | --- |
| `qq_official_mode` | `auto` | 自动使用原生 Markdown；填写模板 ID 时使用模板。`raw` 强制原生 Markdown，`template` 强制模板模式，`off` 使用普通文字和图片 |
| `qq_official_buttons` | `true` | 为当前功能附加快捷按钮；未开通按钮权限可关闭 |
| `qq_official_command_prefix` | 空 | 按钮发出的指令前缀；留空时读取当前 AstrBot 会话的指令前缀 |
| `qq_official_markdown_template_id` | 空 | 可选的、已审核 Markdown 模板 ID |
| `qq_official_markdown_title_key` | `title` | 模板中的标题参数名 |
| `qq_official_markdown_body_key` | `body` | 模板中的正文参数名，必须与标题参数名不同 |
| `qq_official_keyboard_id` | 空 | 可选的、已审核按钮模板 ID；留空使用按当前功能生成的按钮 |

模板模式必须提供有效模板 ID，模板应支持上述标题和正文参数。通常保持默认配置即可；插件会上传生成的卡片到 QQ 官方素材服务，无需自建公开图床。素材准备或增强消息明确被拒绝时会回退普通文字与图片；按钮单独被拒绝时，会先保留 Markdown 卡片、去掉按钮重发。

指令仍受 AstrBot 的管理员权限控制，按钮不能绕过管理员限制。QQ 平台负责投递用户消息；在需要 @ Bot 或指令前缀的接入方式中，按当前平台的要求发送，插件无法处理未投递给机器人的消息。

## 抽卡和快捷按钮

发送 `今日宝可梦`，结果会将宝可梦名字、稀有度与 NEW/闪光标记放在卡片旁，剩余次数、星尘和保底单独显示。图片沿用基础、TCG 或游戏王卡面设置。

快捷按钮每行三个。抽卡等级只显示 C/R/SR/SSR；带卡图的结果使用紧凑标题图，将名字与等级保持在一行，括号内的 NEW 等注记显示为灰色小字。标题图与卡牌独立，标题图无法发送时改用加粗名字和普通注记。

- 「再抽一次」直接提交抽卡指令，仍按正常次数与冷却检查。
- 「我的宝可梦」与收藏页的上一页、下一页按钮可直接查看收藏。
- 「星尘兑换」「发起挑战」「图鉴查询」先填入指令到输入框，补充对象后再发送，避免误操作。

个人收藏、抽卡和兑换按钮限定原使用者。挑战消息中的接战、拒绝按钮限定被挑战者，取消按钮限定发起者。群友想查看自己的收藏，可自行发送 `我的宝可梦`。

## 和群友挑战

官方群消息可能不提供昵称或普通 QQ 号。每位成员先在目标群里发送：

```text
训练家编号
```

这会登记当前会话并显示 `T-XXXXXXXX` 形式的稳定训练家编号。发送 `本群训练家` 可查看已登记成员。编号仅用于当前会话，换群后不同。

发起者选择自己拥有的宝可梦，使用真实平台 @，或写对方名片中的训练家编号：

```text
宝可梦挑战 25 @T-1A2B3C4D 20
```

把编号换成实际对方编号；`25` 是皮卡丘的全国图鉴编号，也可直接写宝可梦名字，`20` 是可省略的回合上限。接收方点击「选择宝可梦接战」，或发送：

```text
接收挑战 卡咪龟
```

双方只能使用自己在本群已获得的宝可梦，选择闪光时在名字或图鉴编号后加 `闪光`。对局不消耗宝可梦和星尘。挑战 5 分钟内有效，可用 `拒绝挑战`、`取消挑战` 结束等待。

只写昵称不会自动找到对方。未登记的群友应先发送 `训练家编号`；编号碰撞时需使用真实 @，系统不会随机选择成员。

## 对战、资料与管理员功能

对战模拟、双方配招与招式效果、完整对战过程、战绩与排行，以及图鉴、招式、特性、相性、队伍分析、筛选、许愿星与冠军赛查询，均使用同一套官方消息适配。收藏和次数仍按群隔离，私聊数据独立。

QQ 官方 Bot 不使用 OneBot 的合并转发接口。选择图片或文字合并转发时，官方平台会用兼容的消息形式保留完整战报；卡片、配招和全部回合不会因转发接口差异被删减。内容超过平台单条限制时会使用普通消息或附件保留完整结果。

管理员的重置次数、增加次数与立绘缓存等指令继续遵守 AstrBot 的管理员权限；管理台使用 Dashboard 登录鉴权。
