# 玩法与指令

[返回首页](../README.md) · [安装与管理](ADMIN.md)

在聊天中直接发送下面的指令即可。`<名称>` 表示要替换成宝可梦名字，`[页码]` 等方括号里的内容可以省略，不需要输入括号。

第一次使用可以依次发送：

```text
今日宝可梦
我的宝可梦
收集资料
宝可梦 皮卡丘
```

收藏、次数、星尘和战绩按群分开保存。群友挑战只能选择自己在当前群已经获得的宝可梦；普通图鉴查询和 `对战 <A> <B>` 模拟不要求拥有它们。

## 今日宝可梦

```text
今日宝可梦
```

群聊可以直接发送这条完整指令，不需要前缀或 @ 机器人。只匹配指令本身（允许两端空白），
聊天中提到它、追加其他内容或只引用旧消息不会抽卡。同一条消息只处理一次。
机器人管理员设置的插件启用、会话限制和指令权限仍然生效。

每天有固定次数（默认 3 次），每次召唤固定数量（默认 1 位）。这两个数字都可以在配置里改：

- 想一次抽 5 位，就把「每次召唤的宝可梦数量」设为 5；
- 想每天只能抽 1 次，就把「每日召唤次数」设为 1。

**每次先按稀有度权重决定档位，再在该档位里等概率选择宝可梦。** 默认概率与卡池规模：

| 稀有度 | 默认概率 | 种族值总和 | 卡池数量（默认形态） |
| --- | --- | --- | --- |
| SSR 传说 | 3% | ≥ 580 | 92 |
| SR 史诗 | 12% | 480–579 | 331 |
| R 稀有 | 30% | 400–479 | 216 |
| C 普通 | 55% | < 400 | 386 |

概率是权重归一化后的结果，不要求相加等于 100；例如 `55/30/12/3` 就是
55% / 30% / 12% / 3%。把某一档设为 0 就不再产出该档。

如果某一档的权重大于 0、但该档卡池为空（例如把阈值调到没有宝可梦的区间），
插件会剔除该档后重新归一化，`抽取概率` 展示的也是实际生效的百分比；SSR 保底
在卡池没有 SSR 时自动不启用，不会把计数一直累积到底。

首次获得的宝可梦会写入图鉴；重复宝可梦折算星尘。开启「把地区形态/超级进化等形态计入卡池」
后，卡池会从 1025 项扩到 1229 项（缺少种族值的形态行会被跳过），每项独立收藏。

## 我的宝可梦与会话隔离

收藏卡片和文本列表中的「序号」是当前收藏列表的全局序号，跨页连续编号；它与全国图鉴
编号不同。知道当前序号即可直接出战，也可以直接填写已拥有的宝可梦名字；
`我的宝可梦` 只用于查看收藏和序号，并非挑战的前置步骤。收藏增加后序号可能改变。

```text
我的宝可梦
我的宝可梦 2
```

`我的宝可梦 [页码]` 只显示自己在**当前群聊**获得的宝可梦，每页 24 位；私聊则按用户独立
保存。同一账号在 A 群和 B 群的收藏、星尘、今日次数与保底进度互不影响。管理台中的
「宝可梦管理」也按相同的会话标识展示，避免跨群误操作。

## 保底

- **SSR 保底**：默认连续 30 次没出 SSR，下一次必出 SSR。计数按用户单独保存，出 SSR 后清零。
- **新宝可梦保底**：默认关闭。设置成 N 后，连续 N 次抽到重复宝可梦，下一次强制未拥有。
- 两套保底互相独立，不会因为一个触发而重置另一个。

## 星尘与兑换

重复宝可梦按稀有度折算星尘（默认 C 2 / R 6 / SR 20 / SSR 80），闪光重复再乘倍率
（默认 3 倍）。星尘用于定向兑换：

```text
兑换宝可梦 皮卡丘
兑换宝可梦 皮卡丘 闪光
```

普通与闪光分开收藏，所以已经拥有普通皮卡丘时仍可兑换闪光皮卡丘。闪光兑换价格默认是
普通价格的 4 倍。

## 收集里程碑

收集数达到 10 / 30 / 60 / 100 / 200 / 400 / 600 / 800 位时，自动发放星尘；100 位起
还会增加当天的额外召唤次数。集齐全部宝可梦有一次性奖励。

## 收藏与管理员指令

| 指令 | 说明 |
| --- | --- |
| `今日宝可梦` | 消耗今日次数抽取宝可梦 |
| `我的宝可梦 [页码]` | 查看自己的收藏，每页 24 位 |
| `收集资料` | 收集进度、闪光数、星尘、剩余次数、保底进度、会话排名 |
| `兑换宝可梦 <名称> [闪光]` | 用星尘定向兑换未拥有的宝可梦 |
| `收集排行` | 当前群/私聊的收集排行 |
| `抽取概率` | 概率、卡池规模与规则说明卡 |
| `图鉴帮助` | 指令总览 |
| `重置今日宝可梦` | 管理员重置自己的今日次数 |
| `增加宝可梦次数 [数量]` | 管理员给自己增加今日次数 |
| `重置本群宝可梦` | 管理员重置本群所有人的今日次数 |
| `下载立绘` | 管理员一键缓存当前卡池的全部立绘 |

`今日宝可梦` 的别名：`抽取宝可梦`、`抽宝可梦`。

其它常用别名：`图鉴菜单` / `帮助菜单`、`抽取规则` / `抽卡概率`、`我的图鉴` /
`图鉴收藏`、`图鉴资料`、`换取宝可梦`、`图鉴排行`。

AstrBot 按完整指令词匹配，`宝可梦挑战` 与 `宝可梦 <名称>` 可分别使用。

## 图鉴与资料查询

| 指令 | 说明 |
| --- | --- |
| `宝可梦 <编号/名称>` | 图鉴卡片（含冠军赛名次） |
| `宝可梦 <名称> 招式表 [等级]` | 可学招式与推荐配招 |
| `宝可梦 <名称> 能力值 [等级 个体 性格]` | 官方公式计算等级能力值 |
| `特性 <名称>` / `招式 <名称>` / `道具 <名称>` | 数据查询 |
| `性格 [名称]` | 25 种性格修正与口味速查 |
| `相性 <属性1> [属性2]` | 防守方向相性 |
| `相性 打 <属性>` | 进攻方向相性 |
| `克制 <宝可梦>` | 推荐克制它的候选 |
| `克制 <A> <B>` | 两只宝可梦多维度对比 |
| `对战 <A> <B> [等级] [详细] [种子=123] [回合=20] [卡片/转发/文本]` | 模拟对战，查看招式效果与回合战报 |
| `队伍分析 <名称...>` | 共同弱点、全队抗性与属性覆盖 |
| `筛选 速度>100 特攻>=120` | 按种族值筛选 |
| `宝冠军 [关键词]` | 冠军赛数据一站式查询 |
| `许愿星 <性格> [个体] [TID SID]` | 许愿星基拉祈种子筛选 |

群聊中也可以 `@机器人` 直接提问，例如「皮卡丘有哪些弱点」。机器人使用的模型支持工具调用时，会自动查询本地图鉴。

## 看懂对战与完整复盘

```text
对战 皮卡丘 喷火龙 50
对战 皮卡丘 喷火龙 50 详细 种子=123
对战 皮卡丘 喷火龙 50 卡片
对战 皮卡丘 喷火龙 50 转发
```

开场显示双方的四招、属性/物理或特殊分类、威力、命中、PP、图鉴说明与**实际模拟效果**。
自动配招来自对应等级的升级招、招式学习器和遗传招，避免将 Z 招式、极巨招式或未实现的
特殊伤害公式当普通高威力招。没有本地学习表时会明确标为演示配招。

对局支持先制度与速度、能力等级（±6）、本系加成、属性倍率、暴击、PP/挣扎、麻痹、灼伤、
中毒、递增剧毒、睡眠/冰冻，以及已登记招式的追加状态、畏缩、回复、吸血、反伤、守住、
蓄力和攻击后休息。每回合写明招式、剩余 PP、命中/失败、伤害与 HP，并记录状态和能力变化。
双方倒下或达到回合上限时判平局。默认能力为 31 个体、0 努力、中性性格。

每回合根据对手属性、预计伤害、HP、异常状态和能力等级选择招式，避免免疫攻击、满血回复、
重复状态和无收益强化，并说明选择理由。这是启发式收益估算，不提供胜率预测，也不预知
对手本回合选招；命中、暴击、追加状态及相同收益的选招仍由种子控制随机结果。
毒属性宝可梦使用剧毒必定命中；火焰车、神圣之火、闪焰冲锋、热水、蒸汽爆炸可解除自身冰冻，
火属性伤害招、热水和蒸汽爆炸可让被命中的冰冻对手解冻。

普通特性只实现飘浮、避雷针、蓄电、引火、储水的属性免疫部分；吸收回血、能力提升、天气、
场地、道具、换人等规则尚未覆盖。蓄力期间仍可被命中；羽栖不会暂时移除飞行属性；
未实现的图鉴效果会在配招中标注。战报用于资料理解和可复现演示，不等同于官方实战计算器。

长对局默认展示前六回合与最后两回合；追加 `详细` 保留全部回合，长消息会按完整行拆分发送。
复制战报中的 `种子=...` 可重复同一场对局。LLM 工具 `simulate_battle` 同样支持 `seed` 和 `detailed`。
静态 `对战` 默认最多 100 回合，可追加 `回合=20` 或 `20回合` 指定 1–100 的上限；
到上限双方尚未倒下时判平局，复盘指令会保留本次回合上限。

配置 `battle_output_mode` 可选择 `card`（默认精美卡片）、`forward`（合并转发）、`text`（文本）。
插件管理台的设置页也提供此选项；命令末尾的 `卡片`、`转发`、`文本` 只覆盖当前对局。
卡片由竞技场封面、双方配招效果页和逐回合复盘页组成，每页最高 1680px，详细模式保留全部
回合。图片总开关 `enable_image_card` 关闭后使用文本；渲染失败也回退到同一场对局的文本。
合并转发支持 OneBot/aiocqhttp 的群聊与私聊，其他平台或发送失败时自动回退文本。

## 与群友对战

```text
宝可梦挑战 皮卡丘 @群友 20
接收挑战 火稚鸡

宝可梦挑战 2 @群友 20回合
接收挑战 1 闪光 详细 卡片
拒绝挑战
取消挑战
对战记录
对战记录 @群友
对战排行
```

| 指令 | 用途 |
| --- | --- |
| `宝可梦挑战 <序号或名字> @群友 [回合]` | 选择自己已经获得的宝可梦，邀请一位群友 |
| `接收挑战 <序号或名字>` | 选择自己的宝可梦并开始对战 |
| `拒绝挑战` | 拒绝收到的邀请 |
| `取消挑战` | 撤回自己发出的邀请 |
| `对战记录 [@群友]` | 查看自己或群友的胜负统计和最近对局 |
| `对战排行` | 查看当前群的对战积分榜 |

直接发送 `宝可梦挑战 <自己的序号或名字> @群友 [回合]`，群友在 5 分钟内发送
`接收挑战 <自己的序号或名字>` 即可开始。无需先查看「我的宝可梦」，知道序号或名称就能选。
中文、英文、日文名字与已拥有的形态名均可用；名字匹配多个收藏时会列出序号供选择。
序号从 1 开始，按当前群的收藏列表排列；图鉴编号不作为收藏序号使用。
没有获得的宝可梦不能出战，也不能替对方选择。双方群内均须有收藏，每位训练家同时只能参与
一个等待或进行中的挑战。选择后冻结收藏键，避免等待期间收藏增加改变序号而错选。

群友挑战的回合上限默认 50，可指定 1–100，支持 `20`、`20回合`、`回合=20`。约定上限由发起方指定，
接收方无需重复填写；到上限双方尚未倒下时记平局。请真正 @ 一位群友，也可使用 `@用户ID`。
也支持 `收藏挑战`、`挑战宝可梦`、`接受对战`、`接受挑战` 等别名；邀请挑战时请使用真正的 @ 提及。

群友对战固定 Lv.50、31 个体、0 努力、中性性格，按本地学习表推荐配招；缺学习表时会明确
标注演示配招。闪光为展示标记，不额外增加能力。普通与闪光在收藏列表共用序号，追加 `闪光` 必须持有对应闪光个体；仅有
闪光时自动使用闪光。对局不消耗宝可梦和星尘，沿用配置的卡片/转发/文本方式。

只有接受并完成的对局才计入双方胜负平统计，取消、拒绝、过期或计算失败不记战绩。
战绩按群隔离，累计统计不截断，每群保留最近 100 场明细，`对战记录` 显示最近五场及种子。
排行榜胜场 3 分、平局 1 分，积分相同依次按胜率、胜场排序；删除群收藏存档会同时删除
该群挑战与战绩。此功能需要开启抽卡系统。
