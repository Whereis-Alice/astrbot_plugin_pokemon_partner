# Mega 图标素材

- `mega-evolution.png`：宝可梦官方《Pokémon LEGENDS Z-A》网站的 Mega Evolution 标识，由原始 SVG 无改绘转为透明 PNG。
- 其余 92 张 PNG：WikiDex 收录的《Pokémon LEGENDS Z-A》原版超级石道具图。文件字节保持原样，渲染时才裁透明留白并缩放。
- `sources.json`：每张图片的来源页面、原图地址、全国图鉴编号、X/Y/Z 对应形态、尺寸和 SHA-256。

当前图鉴中的 96 个 Mega 形态均已覆盖。玛机雅娜的两种颜色共用对应超级石，米立龙的三种姿势共用对应超级石；超级烈空坐不使用进化石。

所有图标随插件本地提供，生成卡片时不联网下载。图片为宝可梦原版图像，来源和权利归属以原页面为准。

来源：[官方 Mega 页面](https://legends.pokemon.com/en-us/mega-pokemon)、[WikiDex 超级石道具图分类](https://www.wikidex.net/wiki/Categor%C3%ADa:Sprites_de_megapiedras)。
