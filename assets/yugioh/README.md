# 游戏王卡面素材

五张 `*-stock.jpg` 从用户提供的游戏王参考素材中，选取不含文字、插画和标记的裸露底纹重新拼接。保留橙棕、玫红、融合紫、近黑和白银的印刷云纹；卡框、属性图标与排版由插件单独绘制。

原始取样范围（左、上、右、下，像素）：

| 底材 | 参考文件 | 范围 |
| --- | --- | --- |
| C | C.png | 105, 290, 1280, 382 |
| R | R.png | 95, 292, 730, 385 |
| SR | SR.png | 23, 107, 46, 570 |
| SSR | SSR.png | 19, 122, 48, 564 |
| SHINY | 闪光.png | 21, 105, 46, 570 |

每张底材为 720 × 1080，运行时按卡面宽度保持纹理尺度。闪光叠加轻微虹彩；介绍栏将相同云纹映射为低对比浅纸色。素材不包含原卡角色、卡名、发行标识或版权页脚。

`icons/level-star.png` 从同一组用户素材的 `C.png` 中提取，范围为 `(1359, 289, 1461, 391)`，使用圆形透明蒙版隔离橙红星球。它保留参考星标的外观。

`icons/attribute-*.png` 为另行绘制的 18 种宝可梦属性圆章及未知属性图标。圆珠使用明暗反射与单字，字体来自插件附带的 [Partner Card Serif](../fonts/README.md)。生成源码保留在 `yugioh_symbols.py` 的 `_draw_jewel` 中；预制 PNG 随插件提供，运行时无需逐像素重新绘制。图标使用独立属性对应关系，未将宝可梦属性合并为游戏王属性。

这些素材以用户提供的参考为来源，不包含完整参考卡图。原参考素材涉及的第三方美术权益仍属于各自权利人；本仓库的代码许可不改变这些素材的权利归属。
