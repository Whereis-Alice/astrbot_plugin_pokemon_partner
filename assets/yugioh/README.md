# 游戏王卡面素材

五张 `*-stock.jpg` 从用户提供的游戏王参考素材中，选取不含文字、插画和标记的裸露底纹重新拼接。保留橙棕、玫红、融合紫、近黑和白银的印刷云纹；属性图标与排版由插件单独绘制。

原始取样范围（左、上、右、下，像素）：

| 底材 | 参考文件 | 范围 |
| --- | --- | --- |
| C | C.png | 105, 290, 1280, 382 |
| R | R.png | 95, 292, 730, 385 |
| SR | SR.png | 23, 107, 46, 570 |
| SSR | SSR.png | 19, 122, 48, 564 |
| SHINY | 闪光.png | 21, 105, 46, 570 |

每张底材为 1080 × 1620，保留取样底纹的色调和纹理对比，运行时按卡面宽度保持纹理尺度。闪光叠加虹彩；介绍栏将相同云纹映射为低对比浅纸色。素材不包含原卡角色、卡名、发行标识或版权页脚。

`frames/` 保留 `C.png` 中的印刷框边，中心透明。各图的外框／内框取样范围为：

| 文件 | 外框 | 透明内框 |
| --- | --- | --- |
| picture.png | 172, 408, 1458, 1695 | 199, 437, 1430, 1667 |
| title.png | 88, 93, 1542, 279 | 107, 112, 1521, 259 |
| description.png | 90, 1755, 1534, 2250 | 110, 1780, 1511, 2223 |
| outer.png | 0, 0, 1626, 2370 | 70, 70, 1556, 2300 |

介绍框和外框的右下角使用干净角落镜像替换，移除原卡标记；透明部分的隐藏颜色也已清除。运行时按九宫格伸缩外沿与介绍框，保留边角厚度，再匹配各档纸色。

`illustration-light.jpg` 取自 `C.png` 的 `(205, 442, 660, 840)`，`optical-light.jpg` 取自 `R.png` 的 `(214, 442, 668, 840)`。两者只含背景光束或光环，不含人物与文字；运行时调整印刷色调，作为宝可梦立绘后的光线。

`icons/level-star.png` 从同一组用户素材的 `C.png` 中提取，范围为 `(1359, 289, 1461, 391)`，使用圆形透明蒙版隔离橙红星球。它保留参考星标的外观。

`icons/attribute-*.png` 为另行绘制的 18 种宝可梦属性圆章及未知属性图标。圆章使用深色珠芯、薄边反光、单字刻字与接触阴影，字体来自插件附带的 [Partner Duel Symbols](../fonts/README.md)。生成源码保留在 `yugioh_symbols.py` 的 `_draw_jewel` 中，并固定使用独立的 `symbol` 字体；预制 PNG 随插件提供，运行时无需逐像素重新绘制。图标使用独立属性对应关系，未将宝可梦属性合并为游戏王属性。

这些素材以用户提供的参考为来源，不包含完整参考卡图。原参考素材涉及的第三方美术权益仍属于各自权利人；本仓库的代码许可不改变这些素材的权利归属。
